# M2 — Analysis: evidence (2026-10-16)

Scope (PRD §4): track map + corner detection, lap/sector/micro-sector split, PB and theoretical best, per-corner metrics, driver fingerprint.

## Done condition
"Corner detection matches the real corner count on at least 3 tracks and deltas sum to the actual lap delta within tolerance."

Status: **met on three synthetic circuits; real-circuit validation pending captures** (Suzuka 18 corners, Silverstone 18; see `docs/CAPTURE_GUIDE.md`). The detector's threshold (radius < 320 m) is a parameter and may need tuning for real sweepers (DECISIONS D13).

Key assertions:
- Corner count 10 / 14 / 6 on `synth-gp`, `synth-street` (chicanes, hairpin), `synth-fast` (260 m sweeper); every detected corner overlaps the generator's arc and is numbered in driving order.
- Radii within 10 % on analytically closed loops (stadium R=50, rounded square R=35).
- GT7 positions project back to lap distance within 2 m; track fingerprint recognises itself and rejects another circuit; sqlite round trip.
- End to end for both games: track learned from the first flying lap, channels built for every lap, PB equals the fastest ground-truth lap, theoretical best ≤ PB, per-corner metrics on all corners, lockups and wheelspin detected and attributed to corners.
- Segments (corner windows + straights) tile [0, L) exactly and their deltas sum to the lap delta within 0.1 s (they telescope, so the match is to the millisecond).
- Micro-sector bests sum to the theoretical best.
