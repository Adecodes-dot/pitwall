## UI
- Debrief tab: summary paragraph, best / theoretical / consistency / assists cards, one card per corner with the instruction, measured facts, and two uPlot overlays (speed; throttle + brake) of the worst lap vs the best lap with entry and apex markers, the next-session plan, progress table when there is history, Export HTML and JSON buttons (`/api/debrief.html`, `/api/debrief`).
- Radio tab: "Ask the engineer" with a push-to-talk button (Web Speech API where available) and a text box; the answer appears in purple and is spoken at the next safe moment.
- In-app check: typed "where am I losing time" → "Turn 3, 0.2, and Turn 7, 0.1." (before the wording polish); debrief overlays rendered for three corners.
- Playwright: `npm run screenshots` writes `m4-{live,analysis,radio,debrief}-{phone,desktop}.png` (see files beside this note once the Chromium download completes).
